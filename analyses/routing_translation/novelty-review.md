# 内容平移路由：为什么现在还不能直接做新模型

更新日期：2026-08-29

## 我们真正想检查什么

ProMoE 会把每个图像 token 分给一位专家。理想情况下，物体在图中移动后，负责这块内容的专家也应大致跟着内容移动，而不是只记住“这是左上角”或“这是中间”。

但绝对位置并不总是坏信息。天空更常出现在上方，地面更常出现在下方。这里要找的不是“任何位置变化都不能改变路由”，而是下面这种更具体的问题：

> ProMoE 是否会对一个与专家真实作用不一致的位置线索过度自信，并且自己的路由对比损失还会继续强化这个错误？

这是一个待验证的问题，不是已经成立的结论。

## 历史脏实验告诉了我们什么

下面的权重来自旧实验。它们虽然最初从第 0 步开始训练，但中途恢复时没有完整封存代码，因此只能帮助提出假设，不能作为论文证据。

旧探针把图像内容、噪声和去噪目标一起平移，只在一个 MoE 层更换专家。所有方案都让每个 token 只调用一位同宽专家，并保留平移后输入自己的路由权重。

- 50K、block 3、24 张图：在高 margin token 上，让专家随内容移动比同支持、同专家数量的随机替换平均少 `0.0379%` 相对 MSE，24/24 张图同向；当随内容移动的专家被原 router 排在第三名以后时，平均少 `0.0273%`，24/24 张图同向。
- 100K、同一批图和设置：两个数分别为 `0.0492%` 和 `0.0445%`，后者 23/24 张图同向。rank >= 3 的差距比 50K 又扩大了 `0.0155` 个百分点。
- 200K 的 24 份原始结果都存在，但没有完成标记和正式汇总。只读重算得到高 margin 约 `0.0531%`、rank >= 3 约 `0.0573%`。这组结果没有通过预先写下的门槛：低噪声处 high-margin 效应反向为 `+0.0049%`，部分 rank >= 3 单元无法形成有效随机对照，而且最大 forced/unforced MSE 差 `7.15e-8` 超过了 `5e-8` 的限制。
- 50K 的水平翻转检查没有通过：均值只有 `-0.0110%`，置信区间跨过 0，只有 10/24 张图同向，单侧检验 `p=0.472`。

因此，最诚实的结论是：旧权重上有一个值得在干净权重复现的平移现象，但它还不能证明“位置捷径”普遍存在，更不能证明某个训练方法有效。

## 旧随机对照还有一个漏洞

旧的随机对照做到了两件重要的事：

1. 改动的 token 位置与内容跟随方案完全相同。
2. 每位替换专家收到的 token 数也完全相同。

但是它把这些专家 ID 在空间上打散了。正确的内容跟随图仍然有连续的局部结构，随机图没有。因此旧结果还可能有另一种解释：

> 连续的专家分配图比被打散的专家分配图更好，而不一定是某位专家真的认出了移动后的内容。

Fresh 复现必须增加“空间结构相近但内容对应故意错误”的对照。没有这个对照，即使再次得到很小的 p 值，也不能把结果解释为内容路由更准确。

## 为什么这个问题与 ProMoE 自身有关

基础 ProMoE 的代码有三点会形成一个可能的反馈环：

1. 固定二维位置编码在进入第一个 DiT block 前就与图像 token 相加，后续 router 看到的是内容和位置已经混合的 hidden state。
2. router 用 token 与可学习原型的余弦相似度做 top-1 分配。
3. routing contrastive loss 先用当前 router 自己的 top-1 结果给 token 分组，再让每个原型贴近自己分到的 token 均值。

第三点没有独立的“正确专家”标签。若早期分配利用了一个容易但不可靠的位置线索，这个分配仍会被当成正标签继续学习。另一方面，未被选中的专家没有在同一次前向中获得“它其实更合适”的直接去噪比较。

这说明“自分配可能强化高置信错误”是一个合理假设，但仅凭代码结构还不能说它已经发生。Fresh checkpoint 上还需要检查 RCL 的实际梯度是否把错误 margin 推得更大。

## 最接近的已有工作

| 工作 | 已经做了什么 | 对本方向的限制 |
| --- | --- | --- |
| [MoGE](https://arxiv.org/abs/2504.09265) | 对 top-k 前的路由分数加分组稀疏约束，使小幅平移、旋转、缩放后的路由表示更稳定 | 不能把普通平移一致性或路由不变正则当成新贡献 |
| [Polysemantic Experts, Monosemantic Paths](https://arxiv.org/abs/2604.17837) | 用 router 矩阵的行空间把 hidden state 精确拆成 router 可见控制信号和 router 不可见内容信号 | 不能声称首次做 router 专属子空间分解；简单低秩投影也不够新 |
| [Learning Subset-Shared Invariances](https://arxiv.org/abs/2606.25665) | 让不同专家学习不同域子集的不变因素，并用路由决定在哪些域对之间做对齐，同时约束置信度、负载和专家差异 | 不能把“不变因素分给不同专家”或“路由决定对齐位置”直接搬来当主创新 |
| [Spatial Mixture-of-Experts](https://arxiv.org/abs/2211.13491) | 在位置确实决定任务规律时，主动利用坐标做细粒度路由 | 提醒我们绝对位置可能有用，不能一刀切删除所有位置信息 |
| [Patch-level Routing in MoE](https://arxiv.org/abs/2306.04073) | 论证 patch router 可以筛掉与标签无关的 patch，并展示其减少虚假相关 | 不能笼统声称首次让视觉 MoE 忽略无关空间信息 |
| [When Are Experts Misrouted?](https://arxiv.org/abs/2605.07260) | 在相同计算量下试用替代专家，用任务误差判断误路由 | 不能把普通专家反事实比较或 utility 监督本身当成新方法 |
| [GRIP](https://arxiv.org/abs/2601.16905) | 用 router 几何空间的零空间投影限制路由更新 | 不能把一般的 router 零空间约束宣传为首次提出 |
| [Not Eliminate but Aggregate](https://arxiv.org/abs/2406.12060) | 用 MoE 专家聚合缓解快捷特征在分布变化下失效 | 不能声称首次研究 MoE 与 shortcut shift |

## 目前明确不批准训练的方案

- 给原图和平移图的路由加普通一致性损失。
- 学一个低秩“位置噪声子空间”，然后直接从 router 输入中减掉。
- 用 DINO 特征直接对齐 token 或 hidden state；这仍然是换了老师的表征对齐。
- 给专家输出加普通正交损失，再把结果解释成内容与位置解耦。
- 直接用一次替代专家 MSE 教 router，而不说明与已有 counterfactual routing 的本质差别。

这些方案要么已有直接近邻，要么只是把成熟模块接到 ProMoE 上，达不到 TPAMI 扩展所需的创新强度。

## Fresh 300K 复现怎样预先锁定

正式复现只使用当前从空目录、第 0 步开始训练的 Fresh Base 300K EMA 权重。看到结果前固定下面的设置：

- 同一批预先锁定的 24 张图和随机种子。
- 6 个 MoE block：`1/3/5/7/9/11`（从 0 开始编号）。
- 三个噪声位置：`0.276/0.5/0.724`。
- 四个平移：latent 上下左右各 2 个像素，也就是 token 网格移动 1 格。
- 主要分组仍是 high-margin 和 transported expert rank >= 3。
- 主要比较改成“正确内容对应”减去“空间结构匹配但内容对应错误”。旧的完全随机对照只作次要结果。

新的空间对照必须同时满足：改动 token support 完全相同、替换专家直方图完全相同、至少 50% 的替换 ID 与正确内容对应不同，而且四邻域专家配对统计与正确图的总变差不超过 `0.10`，也不得比旧随机图更差。任一单元做不到，就把该单元记为不可识别，不能偷偷改用旧随机结果。

block 3 的两个主要分组都要满足以下条件：

1. 平均相对 MSE 差不高于 `-0.02%`，95% 图像聚类 bootstrap 上界低于 0。
2. 至少 18/24 张图同向，单侧 Wilcoxon `p <= 0.05`。
3. 三个噪声位置的均值都为负。
4. 内容跟随方案本身也优于 native，而不只是比错误对照好。
5. 每张图至少有 6 个可识别单元。

跨层检查还要求至少 4/6 个 block 的两个主要分组均值为负，且置信区间上界低于 0。数值控制继续要求 no-op 差为 0，forced/unforced 最大输出差不超过 `5e-6`、MSE 差不超过 `5e-8`。

任何一项失败，都停止把“内容平移误路由”作为主方法动机。不能只挑通过的层或噪声位置。

## 即使复现通过，也还缺什么

复现通过只说明 router 的高置信选择与专家作用之间存在一个空间相关的错位。下一步还要直接测量：RCL 单独产生的梯度，是否会继续增大 native 错误专家相对内容跟随专家的 margin。

只有“错误确实存在”和“ProMoE 的自分配 RCL 确实在强化它”两件事都成立，才有资格设计针对这个反馈环的方法。方法还必须保留有用的位置先验，并用正确内容对应、错误内容对应和等成本随机对应三条从头训练对照证明收益来源。否则仍然只是一个不变学习模块与 MoE 的拼接。
