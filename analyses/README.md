# Analyses Overview

`analyses/` contains runnable analysis entry scripts for the ProMoE-Plus project.
Each Python entrypoint in this directory has a matching Markdown guide with the same basename.

## Entry Scripts

- [`run_tokenwise_tsne.py`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_tokenwise_tsne.py): token-wise routing t-SNE during sampling. See [`run_tokenwise_tsne.md`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_tokenwise_tsne.md).
- [`run_samplewise_pooled_tsne.py`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_samplewise_pooled_tsne.py): sample-wise t-SNE based on pooled block token features. See [`run_samplewise_pooled_tsne.md`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_samplewise_pooled_tsne.md).
- [`run_imagewise_tsne.py`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_imagewise_tsne.py): image-wise t-SNE based on pretrained image encoder features from generated PNGs. See [`run_imagewise_tsne.md`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_imagewise_tsne.md).
- [`run_repa_dyna_heatmap.py`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_repa_dyna_heatmap.py): RGB heatmap visualization of raw dynamic REPA token weights predicted by the `MLP + Sigmoid` token-weight head. See [`run_repa_dyna_heatmap.md`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_repa_dyna_heatmap.md).
- [`run_token_choice_expert_heatmap.py`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_token_choice_expert_heatmap.py): RGB heatmap visualization of token-choice routed expert indices on the final sampled image, arranged by MoE block and denoising step. See [`run_token_choice_expert_heatmap.md`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_token_choice_expert_heatmap.md).
- [`run_compute_flops.py`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_compute_flops.py): FLOPs, activated-parameter, and expert-frequency analysis for a checkpoint. See [`run_compute_flops.md`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_compute_flops.md).
- [`run_mos_routing_analysis.py`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_mos_routing_analysis.py): MoS router teacher block selection analysis — per-block and aggregated frequency histograms, timestep evolution, token variance, and routing entropy. See [`run_mos_routing_analysis.md`](/mnt/miah204/bycao/ProMoE-Plus/analyses/run_mos_routing_analysis.md).
- `run_expert_function_consistency_probe.py`: tests whether shared-expert-relative routed functions follow transported image content and predict exact equal-compute denoising responsibility. See `run_expert_function_consistency_probe.md`.
- `run_expert_function_consistency_probe_batch.py`: runs the pre-registered 24-image, image-cluster-bootstrap confirmation gate for expert-function transport on Base step 50K. See `run_expert_function_consistency_probe_batch.md`.
- [`run_denoising_regret_probe.py`](run_denoising_regret_probe.py): checkpoint-backed comparison of first-order expert-route regret with exact single-token counterfactual MSE. See [`run_denoising_regret_probe.md`](run_denoising_regret_probe.md).
- [`run_denoising_regret_probe_batch.py`](run_denoising_regret_probe_batch.py): resume-safe multi-image, multi-sigma FDRR regret-evidence gate. See [`run_denoising_regret_probe_batch.md`](run_denoising_regret_probe_batch.md).
- [`run_cfg_route_inversion_probe.py`](run_cfg_route_inversion_probe.py): paired conditional/unconditional counterfactual test for CFG route-utility inversion. See [`run_cfg_route_inversion_probe.md`](run_cfg_route_inversion_probe.md).
- [`run_affinity_responsibility_probe.py`](run_affinity_responsibility_probe.py): fixed-dispatch causal audit of whether prototype affinity is calibrated as the routed expert output scale. See [`run_affinity_responsibility_probe.md`](run_affinity_responsibility_probe.md).
- [`run_timestep_utility_probe.py`](run_timestep_utility_probe.py): natural-input audit of exact expert utility, capacity-preserving oracle routing, and cross-sigma utility-rank changes. See [`run_timestep_utility_probe.md`](run_timestep_utility_probe.md).
- [`run_timestep_utility_probe_batch.py`](run_timestep_utility_probe_batch.py): pre-registered discovery/confirmation gates for the natural-input timestep-utility audit. See [`run_timestep_utility_probe_batch.md`](run_timestep_utility_probe_batch.md).
- [`run_count_preserving_cycle_probe_batch.py`](run_count_preserving_cycle_probe_batch.py): locked Base-200K gate for exact denoising utility and first-order fidelity of fixed expert-count 4/6-cycle routing changes. See [`run_count_preserving_cycle_probe_batch.md`](run_count_preserving_cycle_probe_batch.md).
- [`run_compute_exchange_deployability_gate.py`](run_compute_exchange_deployability_gate.py): locked two-stage screen for target-free within-expert 0/1/2-pass action selection followed by sealed exact counterfactual reveal. See [`run_compute_exchange_deployability_gate.md`](run_compute_exchange_deployability_gate.md).
- [`run_learning_credit_balance_probe_batch.py`](run_learning_credit_balance_probe_batch.py): locked frozen-checkpoint gate for routed-expert token-count versus suffix-gradient-credit imbalance and persistence. See [`run_learning_credit_balance_probe_batch.md`](run_learning_credit_balance_probe_batch.md).
- [`run_learning_credit_balance_cross_checkpoint.py`](run_learning_credit_balance_cross_checkpoint.py): sealed Base/Loss-Free step-200K gate for per-block global load balance, count-adjusted suffix-gradient credit, and exact parameter-side empirical Fisher. See [`run_learning_credit_balance_cross_checkpoint.md`](run_learning_credit_balance_cross_checkpoint.md).
- [`run_credit_redistribution_gate.py`](run_credit_redistribution_gate.py): sealed three-arm continuation gate for budget-preserving, expert-matched credit-rate feedback. See [`run_credit_redistribution_gate.md`](run_credit_redistribution_gate.md).
- [`run_routing_translation_probe.py`](run_routing_translation_probe.py): fixed-compute causal audit of whether top-1 routes follow translated content or absolute token coordinates. See [`run_routing_translation_probe.md`](run_routing_translation_probe.md).

- [`run_routing_flip_probe.py`](run_routing_flip_probe.py): fixed-compute causal audit of whether top-1 routes follow horizontally flipped content, including changed-token router margins. See [`run_routing_flip_probe.md`](run_routing_flip_probe.md).
- [`run_routing_translation_stratified_probe.py`](run_routing_translation_stratified_probe.py): fixed-compute translation audit split by native router margin and transported-expert rank. See [`run_routing_translation_stratified_probe.md`](run_routing_translation_stratified_probe.md).
- [`run_phase_default_probe.py`](run_phase_default_probe.py): locked Base-200K test of global versus phase-conditioned default expert outputs and their dense router-gradient approximation. See [`run_phase_default_probe.md`](run_phase_default_probe.md).
- [`run_phase_metric_checkpoint_probe.py`](run_phase_metric_checkpoint_probe.py): locked fresh-50K gate that separates Phase-Metric expert selection from router weighting and verifies route changes with exact equal-compute counterfactuals. See [`run_phase_metric_checkpoint_probe.md`](run_phase_metric_checkpoint_probe.md).
- [`run_fresh_base_routing_audit.py`](run_fresh_base_routing_audit.py): sealed 50K/100K/150K/200K audit of routing accuracy, exact expert-count-preserving reassignment, and phase-dependent expert utility on one fresh-from-zero Base trajectory. See [`run_fresh_base_routing_audit.md`](run_fresh_base_routing_audit.md).
- [`run_finite_horizon_routing_probe.py`](run_finite_horizon_routing_probe.py): compares immediate and 1/2/4/8-step utility of exact-count-preserving expert swaps. See [`run_finite_horizon_routing_probe.md`](run_finite_horizon_routing_probe.md).
- [`run_finite_horizon_routing_probe_batch.py`](run_finite_horizon_routing_probe_batch.py): sealed plumbing/discovery/confirmation gate with image-cluster bootstrap and within-cell candidate-label permutation. See [`run_finite_horizon_routing_probe_batch.md`](run_finite_horizon_routing_probe_batch.md).
- [`run_rcl_responsibility_probe_batch.py`](run_rcl_responsibility_probe_batch.py): sealed support/query gate for testing whether ProMoE's direct RCL prototype update improves held-out grouping while harming tied routed responsibility. See [`run_rcl_responsibility_probe_batch.md`](run_rcl_responsibility_probe_batch.md).
- [`run_routing_semantic_audit.py`](run_routing_semantic_audit.py): locked dirty-discovery audit of whether historical Base ProMoE route IDs agree with independent DINOv2 patch semantics beyond spatial-shift and wrong-image controls. See [`run_routing_semantic_audit.md`](run_routing_semantic_audit.md).

## Shared Modules

Reusable helpers for these entry scripts live in [`analyses/t_SNE/`](/mnt/miah204/bycao/ProMoE-Plus/analyses/t_SNE/), including checkpoint and YAML resolution, ImageNet class utilities, feature capture, partial-result merging, encoder loading, and SVG plotting.
Heatmap helpers live in [`analyses/heatmap/`](/mnt/miah204/bycao/ProMoE-Plus/analyses/heatmap/), including output-path utilities, deterministic sample specifications, dynamic-REPA token-weight capture, token-choice expert-index capture, sampling/merging helpers, and SVG overlay plotting.
FLOPs/statistics helpers live in [`analyses/flops/`](/mnt/miah204/bycao/ProMoE-Plus/analyses/flops/), including checkpoint resolution, model loading, FLOPs accumulation, expert-frequency tracking, activated-parameter tracking, and bar-chart plotting.
MoS routing helpers live in [`analyses/mos_routing/`](/mnt/miah204/bycao/ProMoE-Plus/analyses/mos_routing/), including hook-based routing weight capture (`extract.py`), online statistical aggregation (`aggregate.py`), and histogram/variance/entropy plotting (`plotting.py`).
Denoising-regret helpers live in [`analyses/denoising_regret/`](denoising_regret/), including checkpoint loading, routing interception, exact counterfactual execution, fixed case manifests, and per-cell launch-gate aggregation.
Routing-equivariance helpers live in [`analyses/routing_translation/`](routing_translation/), including reflect-padded latent shifts, horizontal flips, transported route references, matched random controls, router-margin diagnostics, and fixed-ID counterfactual execution.
Natural-input expert-utility helpers live in [`analyses/timestep_utility/`](timestep_utility/), including paired all-expert interventions, constrained assignment, load statistics, and cross-sigma rank analysis.
Phase-default helpers live in [`analyses/phase_default/`](phase_default/), including selected-output sketch calibration, exact missing-expert output evaluation, and local dense router-gradient comparisons.
Phase-Metric checkpoint-gate helpers live in [`analyses/routing_metric/`](routing_metric/), including factorial router overrides, fixed-weight route counterfactuals, image-level bootstrap gates, and split-lock tests.
Fresh Base longitudinal-audit helpers live in [`analyses/fresh_base_routing/`](fresh_base_routing/), including deterministic held-out selection, provenance sealing, multi-GPU execution, and cross-checkpoint decisions.
Finite-horizon routing helpers live in [`analyses/finite_horizon_routing/`](finite_horizon_routing/), including the locked Euler schedule, exact-count swap validation, paired rollouts, and immediate-versus-future rank statistics.
RCL-responsibility helpers live in [`analyses/affinity_responsibility/`](affinity_responsibility/), including deterministic four-rank support selection, DDP-mean direct prototype gradients, fixed-dispatch exact MSE interventions, image-level gates, and sealed multi-GPU execution.
Routing-semantics helpers live in [`analyses/routing_semantics/`](routing_semantics/), including locked input validation, VAE posterior-mode reconstruction, frozen DINOv2 patch measurement, structure-preserving controls, and image-level statistics.
