基线 / Baseline: 基础 ProMoE-TC（cond/uncond 分流、原型余弦 token 路由、shared expert 与路由对比学习）；直接对照 / Parent: B_clean_route_student_ratio0_corr_router_kl_detach_base（真实干净图 teacher、KL detach-base、50% 随机参考丢弃）。

核心改动 / Core changes（相对基线，重点优先）:
1. 取消随机参考丢弃 / no reference dropout：no_reference_prob 从 0.5 改为 0.0，启用 zero_reference_at_t1000。仅在当前 t 精确等于 1000 时将学生参考置零；参考 sigma 被截到 1 的正常样本仍保留参考。采样照旧以首步全零参考启动，之后用上一采样步的 CFG 融合速度构造参考。
2. 干净图 teacher / real-clean teacher：teacher 仍读取真实干净 latent，在 t=0 用未矫正路由监督学生；KL 对本层原分数停止直接梯度，实际路由仍用原分数加矫正。与 B_estimated_route_student_corr_router_kl_detach_base_no_ref_drop 共享无随机参考丢弃策略，只改变 teacher 输入来源；配合两组 50% 对照构成 2×2。
3. 四卡训练与评估 / pipeline：从 outputs/ProMoE_TC_B_clean_route_corr_router/004_ProMoE_B_clean_route_student_ratio0_corr_router_kl_detach_base_no_ref_drop/ 独立训练。300K 与 500K 均评 250 步、CFG 1.0 / 1.5 各 50K。仅当 300K 两项 FID 分别严格低于 30.86 / 9.73 时续训自身 checkpoint 至 500K，恢复时复核门槛。
