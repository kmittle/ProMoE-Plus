实验 / Experiment: 1.1-B_phase_metric
model_name: ProMoE_TC_B  |  config: configs/004_ProMoE_B_phase_metric.yaml
基线 / Baseline: 基础 ProMoE-TC（conditional cond/uncond routing、静态 `cluster_centers` cosine routing、shared expert 和 routing contrastive guidance）；直接父变体 / Parent: 基础 ProMoE-TC

核心改动 / Core changes（相对基线，重点优先）:
1. 阶段条件路由度量 / phase-conditioned routing metric：在原有 token-prototype cosine affinity 上增加 `PhaseConditionedRoutingMetric` 的低秩 residual。该 residual 同时使用 token 坐标、prototype 坐标和归一化 diffusion timestep 的 Fourier features，并由 expert-specific gain 调整；它只改变 routed expert 的 affinity，不改变 cond/uncond 分流、top-1 选择预算或 shared expert 路径。
2. 零起点与训练要求 / zero-start and fresh training：`phase_to_rank` 从零初始化，因此启用模块时 step-0 residual 为零；metric 的私有初始化 generator 不消耗 Base 的全局 RNG，保证原有权重的初始化序列不被改写。由于新增 metric 参数带来不同的 state keys，本实验必须使用独立输出目录从 step 0 训练到 501K，不能加载旧 Base checkpoint。
3. 固定实验设置 / controlled setting：`rank: 8`、`num_fourier_bands: 4`、`scale: 0.25`、`num_train_timesteps: 1000`，seed 为 0，global batch 为 256，lr 为 `1e-4`；使用本地 encoded latents，采样/评估点为 300K 和 500K、CFG 1.0/1.5。相比基础路由只增加低秩 router arithmetic，激活专家数保持不变。
