model_name: ProMoE_TC_B_clean_route  |  config: configs/004_ProMoE_B_clean_route_student_ratio0_align_warmup200k.yaml
基线 / Baseline: 基础 ProMoE-TC（cond/uncond 分流、余弦原型路由、共享专家、student 侧路由对比学习）；直接父变体 / Parent: clean_route_student_ratio0（同一模型的干净 teacher 路由蒸馏，从第 0 步固定使用 5e-4）。

核心改动 / Core changes（相对基线，重点优先）:
1. 线性渐增 / Linear KL warmup：align_start_step: 0、align_warmup_steps: 200000。蒸馏系数从第 0 步的 0 线性增至第 200000 步的 align_lam: 0.0005；100K 时为 0.00025，200K 后保持。 只调 KL 系数；两种调度到 300K 的累计系数均约等效 200K 步满系数蒸馏。
2. 教师与训练信号 / Teacher and gradients：teacher_sigma_ratio: 0、contrastive_source: student、align_temperature: 0.07。teacher 使用当前同一模型的干净 latent、t=0、no-grad 前向；系数为 0 时仍保留 teacher 诊断。FM 和 student routing contrastive 始终启用，无矫正器、无新增模型参数或 checkpoint buffer。train.py 传入绝对优化步 training_step，梯度累积共用该步数，续训不重置调度；clean_route_align_weight 记录有效系数，eval 不依赖训练步数。
3. 运行 / Run：从头训练到 300K → 评估 → 续训本实验权重到 500K → 再评估；300K 评估成功后自动续训，不按 FID 阈值筛选。自动匹配 4 卡，global batch 256、seed 0、lr 1e-4、workers 16；latent_data_path 为 /mnt/data2/yujie/code/Dataset/ImageNet/sd-vae-ft-mse_Latents_256img_npz。两个节点均为 250 步采样、CFG 1.0/1.5 各 50K 张图，输出 outputs/ProMoE_TC_B_clean_route/004_ProMoE_B_clean_route_student_ratio0_align_warmup200k/。PROMOE_RESUME=1 只续接本实验权重；已有固定系数实验作为对照，不另建重复基线。
