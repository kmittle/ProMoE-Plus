实验 / Experiment: B_top3
model_name: ProMoE_TC_B  |  config: configs/004_ProMoE_B_top3.yaml
基线 / Baseline: 基础 ProMoE-TC B（cond/uncond 分流、12 个条件 token 原型专家、固定 shared expert、专用 uncond expert、routing contrastive）；直接父变体 / Parent: 同一基础模型的 token Top-1 配置。容量对照 / Capacity counterparts: B_shared_plus_cond_image_e4_token_top2 与 B_shared_plus_cond_image_e4_image_top2。

核心改动 / Core changes（相对基线，重点优先）:
1. Base token Top-3 / E14A3S1U1：复用 models/models_ProMoE_TC.py 和 ProMoE_TC_B 注册，仅将 top_k 设为 3。每个 cond token 从 12 个 routed experts 选出 3 个不同专家，以各自原始余弦分数加权求和，再加 shared 输出；router_weight_mode=identity，不做 softmax 或 Top-K 权重归一化。use_top_k_for_routing_contrastive=True，将三个分配都用于原有 routing contrastive（系数 1、温度 0.07）。不增加模型参数；uncond token 仍只执行一次专用 uncond FFN，并加 shared 输出。无 image-wise 专家、pooling、clean teacher 或矫正 router。
2. FFN 预算对齐 / Matched FFN matrix work：routed、shared、uncond FFN hidden dim 均保持 1536。cond 激活宽度和为 3×1536 + shared 1536 = 6144，等于两组 image-wise 容量实验的 token Top-2 + image Top-1 + shared 或 token Top-1 + image Top-2 + shared；uncond 激活宽度和均为 1536 + 1536 = 3072。对齐的是实际执行的 FFN 主矩阵计算：CPU 检查在一个条件图和一个无条件图、各 12 tokens、hidden_size=768 下，三组每个 MoE 层的 FFN 矩阵 MACs 都为 169,869,312，已核对 Top-3 输出等于三个专家的手工加权和加 shared。完整模型 FLOPs 不严格相等：image-wise 两组额外承担 pooling/router 计算，并拥有额外图级专家参数；本对照不按 image-wise 的总参数量扩充 token 专家池，也不为匹配原 Top-1 成本而缩窄专家。
3. 训练与运行 / Training：seed=0、global batch=256、lr=1e-4、img_num_workers=16、4 卡。从零训练到 300K → 评估 → 续训本实验权重到 500K → 再评估；300K 评估成功后自动续训，不按 FID 阈值筛选。两个节点均为 CFG 1.0/1.5 各采样 50K 张，sample_batch_size=128/卡、250 步。使用 train.py 和当前 scripts/template.sh，启动时申请 4 张空闲 GPU；latent 默认 /mnt/data2/yujie/code/Dataset/ImageNet/sd-vae-ft-mse_Latents_256img_npz，可由 PROMOE_LATENT_PATH 覆盖。独立输出为 outputs/ProMoE_TC_B/004_ProMoE_B_top3/，不复用 Top-1 或 image-wise 实验的 checkpoint。
