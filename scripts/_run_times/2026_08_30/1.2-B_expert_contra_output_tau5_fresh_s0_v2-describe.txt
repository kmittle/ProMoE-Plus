实验 / Experiment: 1.2-B_expert_contra_output_tau5_fresh_s0_v2
model_name: ProMoE_TC_B_expert_contra  |  config: configs/004_ProMoE_B_expert_contra_output_tau5_fresh_s0_v2.yaml
基线 / Baseline: 基础 ProMoE-TC（cond/uncond 分流、learnable cluster_centers 余弦 top-1 路由、shared expert 和 routing contrastive guidance）；直接父变体 / Parent: 旧 expert_contra_output 在相同六个 MoE blocks 上分开不同专家的平均输出，expert_contrastive_temperature 为 0.5。

核心改动 / Core changes（相对基线，重点优先）:
1. 只校准专家输出分离损失的温度：expert_contrastive_temperature 从 0.5 提高到 5.0，expert_contrastive_lam 保持 0.5。代码中的损失是 exp(-L2 distance / temperature)；提高 temperature 会减缓大距离处的指数衰减，本实验检查旧设置是否因损失接近 0 而没有真正约束专家。
2. 其余模型行为不变：仍在 0-based blocks [1, 3, 5, 7, 9, 11] 比较 conditional routed experts 的平均输出；top-1 路由、token dispatch、shared/uncond experts 和系数为 1 的 routing contrastive loss 都不变。该损失只用于训练，不增加参数，也不改变采样路径。
3. 公平的从头训练：global_seed=0、4 GPUs [4, 5, 6, 7]、global batch=256、lr=1e-4、16 data workers，并读取 /home/dev/imagenet-1k 下的 encoded latents。`PROMOE_STRICT_PROVENANCE=1` 要求启动代码干净且已 push，并把代码、配置、数据顺序和训练进度写入 checkpoint；`_v2` 新输出目录从 step 0 开始，在 300K 和 500K 分别生成 CFG 1.0/1.5 的 50K 样本并按 OpenAI 协议评估。
