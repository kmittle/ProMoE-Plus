实验 / Experiment: 8.1-B_lsreg_fixed0p20
model_name: ProMoE_TC_B_lsreg  |  config: configs/004_ProMoE_B_lsreg_fixed0p20.yaml
一句话 / TL;DR: 训练时给一个辅助损失“松一点绑”，别逼专家去死记那些样本很少、算出来本就不准的东西；这一档定成 0.20，是这批实验里最标准的基准档。

这个实验在做什么（大白话）:
1. 问题背景：模型训练时有个辅助任务，要让每个专家的“代表向量”去贴近分给它的那批图像块的平均。可有的专家分到的块很少，这个平均本身就抖、不靠谱，硬逼它精确对上就是在背噪声、容易过拟合。这个实验给这个对齐任务加一点“容错余地”，别要求 100% 对上（这套做法叫标签平滑 label smoothing，余地大小用 ε 表示，ε 越大越松）。
2. 这一版怎么设：所有专家统一给同一个余地（ls_mode=fixed，ε=0.20）。在这里只有 12 个专家，0.20 这个力度大致相当于图像分类里 1000 类时常用的 0.10，算是“力度等效”的标准基准；那些按忙闲动态调的版本也都是围着 0.2 这个中间值上下浮动的。
3. 它只动了这一个辅助损失，路由怎么走、专家怎么算、块怎么分都没变，所以从第 0 步开始就和原始模型一模一样，能直接接着原模型的存档继续训。
4. 整组在做的事：把这个“余地”从小到大扫一串（0.05 / 0.10 / 0.20 / 0.30 / 0.40），画出“松多少 → 生成质量(FID)怎么变”的曲线，这一档是中间的锚点；同时要跟同族另一套“治专家忙闲不均”的做法(lbcontra)比高低，以对齐步数的 FID 为准。
