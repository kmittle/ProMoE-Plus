基线 / Baseline: 基础 ProMoE-TC（conditional prototype routing + shared expert + routing contrastive loss）；直接父变体 / Parent: `_param`（全 6 个 MoE block 的 routed-expert L2 排斥，`tau=0.7`）。

核心改动 / Core changes（相对基线，重点优先）:
1. 只把参数排斥温度 `expert_contrastive_temperature` 从 `0.7` 改为 `7`，其余配置不变。原始 L2 距离下，这会显著增强正则在训练初期的作用，用来检验父变体的温度是否过小而近似失效。
2. 仍是 12 个 routed experts、`expert_contrastive_mode: param`、`lambda=0.5`，只在 `[1,3,5,7,9,11]` 六个 MoE block 计算；shared/unconditional expert 不参与。与 tau0p07 一起构成只改温度的对照。
3. 补测固定 `global_seed=0`、GPU 0--3、全局 batch 256，从头训练到 500K；在 300K/500K、CFG 1.0/1.5 使用 OpenAI evaluator 各评估 50K 张图。
