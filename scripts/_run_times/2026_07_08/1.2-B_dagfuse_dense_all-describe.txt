核心改动 / Core changes（相对基线，重点优先）:

2. `fuse_apply: all` / 作用范围：融合作用于全部 token（对照姊妹实验 1.1 的 cond=仅 cond token 切片）。这是 cond↔all 的消融轴。
3. step-0 与路由 / step-0 & routing：输出投影 zero-init（`_basic_init` 后二次清零）→ step-0 与 base 逐比特一致、非严格可加载；只改 shared 输出，路由与 base 逐比特不变。
