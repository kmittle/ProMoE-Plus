实验 / Experiment: 1.1-B_ec_bc_proto_t_direct_v2
model_name: ProMoE_EC_BC_B_proto_t  |  config: configs/004_ProMoE_B_EC_BC_proto_t_direct_v2.yaml
基线 / Baseline: 基础 ProMoE-EC（条件路由分离 uncond 专家 + 静态可学习 cluster_centers 原型的余弦相似度两步路由 + routing contrastive 损失）；直接父变体 / Parent: ProMoE_EC_BC_B（EC-BC 批展平 Expert-Choice 路由，静态原型）

核心改动 / Core changes（相对基线，重点优先）:
1. 时间步条件原型 / timestep-conditioned prototypes（proto_t）：把固定的可学习 `cluster_centers` 换成由 `PrototypeMLP(cluster_centers, t_emb)` 逐样本（per cond-sample）生成的原型 `prototype_t`（shape `(B_cond, E, D)`），使路由的余弦相似度在与该噪声水平对齐的特征空间中计算；为此每个 DiT block 的 forward 多接收一个 `t_emb` 参数（`block(x, c, label, t)` → MoE `forward(..., t_emb)`），且每个 MoE block 各自持有一个 `prototype_mlp`。这是相对父变体 ProMoE_EC_BC_B 的唯一新增机制。
2. `direct` 原型更新模式 / update mode（`proto_t_update_mode: "direct"`）：`prototype_t = proto_proj(cc) + MLP(concat(LN(cc), LN(t_emb)))`，其中 `proto_proj` 为恒等初始化（`nn.init.eye_`）的可训练 `Linear(D→D)`（skip 走 RAW cc）、`fc2` 零初始化 → step-0 与基础 ProMoE 完全等价（`I@cc + 0 == cc`），但 cc→原型 的映射可训练（非硬编码恒等）；`proto_proj` 相对 `residual` 模式每个 MoE block 增加约 +0.59M、全模型约 +3.5M 参数（B 尺度 interleave 下 6 个 MoE block）。相对父变体的 `residual` 模式（`cc + MLP(...)`，无 `proto_proj`）这是本实验的消融轴。注：blanket xavier 初始化后会重新执行（re-assert）PrototypeMLP 的 init 以保住 step-0 不变量。
3. EC-BC 批展平 Expert-Choice 路由（承自父变体）：相对原始 token-choice ProMoE（ProMoE-TC）的逐 token top-1 路由、以及基础 ProMoE-EC 的逐图像（per-image）Expert-Choice，本变体让各 cond 专家在批展平的 cond-token 池（`T = B_cond*S`）上各取 top-k（容量 `k = max(1, min(int(T/E*top_k), T))`，`top_k=1`、`E=num_routed_experts=12`），经高级索引 gather（`flat_input[flat_indices]`）+ `index_add_` 派发、并按 gating 加权回散；uncond 样本（label==1000）仍走专属 uncond 专家、shared expert 对全部 token（含 uncond）叠加；routing contrastive 辅助损失（`lam=1`、`temperature=0.07`、`router_weight_mode=identity`）仍以 `AddAuxiliaryLoss` 注入梯度、forward 返回普通张量。
