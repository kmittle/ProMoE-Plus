实验 / Experiment: 2.1-B_ec_bc_proto_t_residual_v2
model_name: ProMoE_EC_BC_B_proto_t  |  config: configs/004_ProMoE_B_EC_BC_proto_t_residual_v2.yaml
基线 / Baseline: 基础 ProMoE-EC（静态可学习 cluster_centers 原型 + 两步路由 + routing 对比损失）；直接父变体 / Parent: ProMoE_EC_BC_B（EC-BC 批展平 Expert-Choice，静态原型）

核心改动 / Core changes（相对基线，重点优先）:
1. 时间步条件原型 / timestep-conditioned prototypes（proto_t）：把固定可学习的 `cluster_centers` 换成由 `PrototypeMLP(concat(LN(cluster_centers), LN(t_emb)))` 逐样本生成的原型 `prototype_t` (B_cond, E, D)，使余弦相似度路由在与噪声水平对齐的特征空间中进行；为此 DiTBlock/MoE block forward 多接收一个 `t_emb` 参数（`block(x, c, label, t)` → `SparseMoeBlock.forward(..., t_emb)`），每个 MoE block 各持一个 `PrototypeMLP`。相对父变体 ProMoE_EC_BC_B 的静态原型，这是本实验的定义性改动。
2. `residual` 原型更新模式 / update mode（`proto_t_update_mode: "residual"`，默认值）：`prototype_t = cluster_centers + MLP(concat(cc, t_emb))`，其中 fc2 零初始化 → step 0 时 MLP delta 为 0、`prototype_t == cluster_centers`，与基础 ProMoE step-0 逐位等价。相对 sweep 兄弟 `direct` 模式（`proto_proj(cc) + MLP(...)`，恒等初始化的可训练 `proto_proj`，额外约 +3.5M 参数），residual 不引入 `proto_proj`，是该消融轴的默认/轻量端。
3. EC-BC 批展平 Expert-Choice 路由：相对基础 ProMoE-TC 的逐 token top-1 token-choice，专家在批展平的 cond-token 池（T = B_cond*S）上各取 top-k（容量 `k = T/E * top_k`，`top_k: 1`），经 `torch.topk` + 高级索引 gather 派发、`index_add_` 加权回散；`router_weight_mode: identity`、`routing_contrastive_lam: 1`（温度 0.07，top-k 子集做对比），辅助对比损失仍通过 `AddAuxiliaryLoss` 注入、forward 返回纯张量。
