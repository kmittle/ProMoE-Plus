核心改动 / Core changes（相对基线，重点优先）:
1. 仅改变采样参考 / CFG-fused reference：corr_reference_velocity: cfg；用当前步 CFG fusion 后的速度及更新前的 latent、sigma 估计干净 latent，留给下一步 cond 路由矫正器。实际 Euler 步进仍使用 CFG fusion 后速度；首步零参考、uncond 分支无矫正及前向次数保持原定义。conditional 是默认开关，CFG=1.0 时两种参考相同。
2. 权重复用 / Existing checkpoints：读取 outputs/ProMoE_TC_B_clean_route_corr_router/004_ProMoE_B_clean_route_student_ratio0_corr_router/checkpoints/ 下 ckpt_step_300000.pth 和 ckpt_step_500000.pth 的 ema_model_state_dict，严格匹配模型参数；不训练、不复制权重。路径从原训练/续训脚本的 CONFIG、model_name 和输出规则推导，运行时相对目标服务器仓库根目录解析；开始采样前检查所有待补组合所需的权重。
3. 补充评估 / Missing evaluations：自动匹配 4 卡，seed=0，250 个采样步，sample_batch_size=128/卡；覆盖 300K/500K × CFG 1.0/1.5，每组 50K 张图。PROMOE_RESUME 默认 1，逐组跳过已有有效 FID/IS；CFG=1.0 也在本实验目录重新采样，不借用 conditional 参考实验的结果。每组独立启动采样，seed 不受哪些组合被跳过影响；不宣称与原先连续评估多个 CFG 的随机数序列逐图配对。
4. 结果布局 / Output layout：保留历史 _cfg_ref_300k 名称以补齐同一个实验，输出仍为 outputs/ProMoE_TC_B_clean_route_corr_router/004_ProMoE_B_clean_route_student_ratio0_corr_router_cfg_ref_300k/。corr_reference_separate_output: True 保持标准内部布局 sample/step300000 或 step500000/img..._ema/images；采样方式由实验根目录区分。续接时可将旧 _corr_ref_cfg 样本目录连同图片、NPZ 和指标整体迁移到标准名称；两个布局同时存在时拒绝合并。
